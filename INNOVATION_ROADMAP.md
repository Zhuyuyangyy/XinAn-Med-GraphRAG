## Patent Portfolio

### Patent 1: OCR+NLP Pipeline for Classical Chinese Medical Texts

**Title:** 一种基于OCR与NLP的中医古籍知识自动提取方法及系统

**Technical Field:** Natural Language Processing, Optical Character Recognition, Knowledge Engineering

**Background:**
- Classical Chinese medical texts are primary sources of TCM knowledge
- Manual extraction is time-consuming and error-prone
- Existing OCR systems perform poorly on classical Chinese
- No integrated pipeline for end-to-end knowledge extraction

**Technical Solution:**
1. **Multi-modal OCR Engine**
   - Specialized model for classical Chinese character recognition
   - Handwriting style adaptation using transfer learning
   - Layout analysis for complex page structures
   - Confidence scoring and error correction

2. **Classical Chinese NLP Pipeline**
   - Word segmentation for classical Chinese
   - Named entity recognition for medical terms
   - Relationship extraction using dependency parsing
   - Coreference resolution across paragraphs

3. **Knowledge Graph Auto-Construction**
   - Entity linking to existing knowledge base
   - Conflict detection and resolution
   - Temporal reasoning for historical context
   - Quality assessment and validation

**Novel Aspects:**
- First integrated OCR+NLP pipeline for classical Chinese medical texts
- Novel character recognition model trained on medical texts
- Context-aware entity disambiguation
- Automated knowledge graph construction with quality control

**Claims:**
1. A method for extracting medical knowledge from classical Chinese texts, comprising:
   - OCR processing with style adaptation
   - Classical Chinese text segmentation
   - Medical entity recognition
   - Relationship extraction
   - Knowledge graph construction

2. The method of claim 1, wherein the OCR processing includes:
   - Character-level confidence scoring
   - Layout-aware text extraction
   - Error correction using language models

3. A system implementing the method of claim 1, comprising:
   - OCR module
   - NLP processing module
   - Knowledge extraction module
   - Graph construction module

**Expected Impact:**
- 10x faster knowledge extraction
- 95%+ accuracy for entity recognition
- Automated processing of 100+ ancient texts
